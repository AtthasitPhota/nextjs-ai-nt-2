# Repository Quick‑Start & Gotchas

- **Setup**: copy `.env.example` → `.env` before any command.
- **Dev server**: `npm run dev` (runs `next dev`). Uses App Router under `src/app`.
- **Build**: `npm run build` then `npm start` for production.
- **Lint**: `npm run lint` (ESLint v9, config in `eslint.config.mjs`).
- **Tests**: `npm test` runs Vitest (`vitest.config.ts` sets jsdom, resolves `@` → `src`). Use `npm run test:watch` for watch mode.
- **Prisma**: after installing run `npx prisma generate` to create client (schema at `prisma/schema.prisma`).
- **Remote images**: only `www.fffuel.co` and `api.codingthailand.com` are whitelisted in `next.config.ts`; add domains there to load external images.
- **Alias**: import paths using `@/…` resolve to `src/` (TS config and Vite alias). Avoid relative imports deep in the tree.
- **Component cache**: `cacheComponents: true` in Next config may affect hot‑reload; restart dev server after config changes.
- **Untracked files**: `vitest.config.ts`, `vitest.setup.ts`, and test files are currently untracked; add them to VCS if you need CI.
- **Agent block**: the block at the top is regenerated by `next dev`; keep it to avoid diff noise.
